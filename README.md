# Analytics Dashboard — mockup recreation

Static HTML/CSS recreation of the Juice Lab "Analytics Dashboard" shots.

- `index.html` — both screens on one page. `#overview` (default) is *Environmental Risk Overview*, `#map` is *World Risk Map*; the first two sidebar buttons switch between them.
- `styles.css` — layout on a fixed 2000×1500 artboard, scaled to fit the window.
- `charts.js` — draws the sparklines, dot matrix, trend lines and bar charts as SVG (data traced from the mockups).
- `assets/` — raster pieces cut from the mockups (3D relief maps, avatar, insight orb, globe).
- `mockups/` — the reference shots used for overlay/diff comparison.
